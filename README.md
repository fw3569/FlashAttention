## Flash Attention CUDA Implementation
基于 CUTLASS 的 Flash Attention 自定义 CUDA 实现，使用 PyTorch 通过 ctypes 调用。

### 实现说明
`attention_forward` — Native attention（cublasGemmStridedBatchedEx + softmax + cublasGemmStridedBatchedEx），fp16乘法中间结果用fp32保存，作为baseline。

`flash_attention_tensor_op_forward` — Flash Attention FP16，使用CUTLASS的Tensor Core MMA与自定义online softmax，使用cp.async和ldmatric双缓冲加载数据，使用split k支持A800的108个sm。

### 运行环境
- **CUDA**: 12.8
- **CUTLASS**: 4.4.2
- **torch**: 2.7.0+cu128
- **xformers**: 0.0.30.post

### 构建前配置
硬编码了一些路径，使用前需根据本机环境修改

**./src/setup.py**

- `cutlass_path` — cutlass include路径

### 构建和运行
Windows + MSVC 环境下，x64 Native Tools Command Prompt中

``` bash
cd ./src
python setup.py
python main.py
```

### 测试

| 指标 | 参数 |
| :--- | :--- |
| **GPU** | NVIDIA Tesla A800 80G |
| **Compute Capability** | 8.0 (Ampere) |
| **SM 数量** | 108 |
| **显存大小** | 80 GB |
| **显存带宽** | 2 TB/s |
| **理论算力(FP16)** | 312 TFLOPS |

**测试参数**：batch和head数固定为1，测试seq_len=256,512,1024,2048,4096,8192,16384,32768，head_dim=64,128。
**测试方法**：耗时使用python打点`time.perf_counter`测试，100次warmup，100次计时运行取平均值。HBM读写量是使用ncu检查`dram__bytes_read.sum + dram__bytes_write.sum`，含多个kernel会手动累加，不做warmup。由于读写量计数需要用ncu，云平台权限不足，硬件使用的是本地的sm450，由于部分库不支持该硬件，显存也较小，会缺少一些测试数据。另外测试中耗时太长的测试样例会跳过。

## Flash Attention CUDA Implementation
基于 CUTLASS 的 Flash Attention 自定义 CUDA 实现，使用 PyTorch 通过 ctypes 调用。

### 总结

### 环境
- **CUDA**: 12.4
- **CUTLASS**: 4.4.2
- **torch**: 2.6.0+cu124
- **CUDA Architecture**: sm_75（RTX mx450/Turing）

### 构建前配置
硬编码了一些路径，使用前需根据本机环境修改

**./src/setup.py**

- `cutlass_path` — cutlass include路径

### 构建和运行
Windows + MSVC 环境下，x64 Native Tools Command Prompt中

``` bash
cd ./src
python setup.py
python main.py
```

### 实现说明
提供三个 attention 变体：

`attention_forward` — Native attention（矩阵乘 + softmax + 矩阵乘），支持fp16和fp32，fp16版本中间结果用fp32保存，作为baseline。

`flash_attention_simt_forward` — Flash Attention FP32，使用 CUTLASS SIMT warp MMA。

`flash_attention_tensor_op_forward` — Flash Attention FP16，使用 CUTLASS Tensor Core MMA。

**测试参数**：延迟测试部分总token数量固定为8192，总隐藏层维度固定为256，测试seq_len=256,512,1024,2048,4096,8192，head_dim=64,128。读写量测试部分batch和head数固定为1。
**测试方法**：耗时使用python打点`time.perf_counter`测试，100次warmup，100次计时运行取平均值。HBM读写量是使用ncu检查`dram__bytes_read.sum + dram__bytes_write.sum`，含多个kernel会手动累加，不做warmup。其中耗时太长的测试样例会跳过。
